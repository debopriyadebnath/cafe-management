Sunshine Café Ordering System ☕🍕

This is a simple Python program that simulates an ordering system for a café.
Users can view the menu, place an order, and see the total bill amount.

📋 Features

Displays a menu with food & drink items along with their prices.

Allows the customer to order an item from the menu.

Provides an option to order a second item.

Calculates and displays the total bill.

Prints a thank-you message at the end.

🛠️ How It Works

The program shows a menu of items and their prices.

The user enters the name of the first item.

If it exists in the menu, it gets added to the order.

If not, the program shows an error message.

The user is asked whether they want to order another item.

The total order amount is calculated and displayed.

A thank-you message is printed.
